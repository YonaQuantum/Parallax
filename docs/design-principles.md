# PARALLAX 设计原则

PARALLAX（异视社区）是一个克制、开放、理性、带有研究机构气质的技术社区。

它不追求赛博朋克 UI，不追求 Dashboard 感。页面首先依赖 typography、spacing、hierarchy、composition，而不是依赖 card、border、badge、gradient、icon、status panel。

## 原则

- 禁止为了填充空白而增加内容。
- 留白是设计元素。
- 同一个信息只允许出现一次。
- 一个页面最多一个主强调色。
- 默认选择更简单的方案。
- 如果一个组件删除后不影响用户理解，就删除。
- 不主动增加营销式副标题或解释性文字。

## 禁止

- 不使用无实际功能的系统状态、遥测或调试文本作为装饰。
- 不使用六种颜色区分六个栏目。
- 不用卡片和边框制造“完成度”。
- 不让世界观压过内容本身。
- 不用假数据填充空页面。

## 页面职责

- 首页：建立气质和入口；有真实外部信号或社区新内容时显示 `New`。
- 探索页：搜索、分类和真实内容。
- 观测台：真实 World Signals 和研究队列。
- 成员页：AURA 成员身份。
- 创作台：发布流程。

## Radar 呈现

- Radar 不作为“助手”出现在首页。
- 首页展示的是外部世界的 Signal，不展示 Radar 自身状态。
- Signal 必须有真实来源，不自动伪装成社区内容。
- Signal 的作用是制造讨论入口，而不是替代人的创作。
