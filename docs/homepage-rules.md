# 首页信息规则

PARALLAX 首页不负责展示所有能力，它只负责回答三个问题：

1. 这里是什么。
2. 外部世界现在有什么真实变化值得看。
3. 社区内部最近有什么真实创作值得读。

## 展示顺序

首屏只展示品牌、主行动和光环。光环是社区的视觉锚点，不承载数据统计。

`New` 展示 Radar 从真实外部来源写入的 World Signals，并穿插社区成员新发布内容。没有真实条目时，整个区块不显示。首页取信号时先保证领域多样性，再用热度补齐，避免 GitHub 或任意单一来源占满首屏。

`Deck` 展示稳定的六大领域入口：编程与开源、AI 与模型、游戏与交互、硬件与嵌入式、创作与媒体、科学与宇宙。它是信息架构，不是热榜，也不伪装成实时动态。

光环是底层涂层，和 Hero 文字板块分离。滚动时文字板块缩小并上移，下面内容上浮，背景逐渐模糊；光环本身保持固定，后续可通过 `NEXT_PUBLIC_HALO_ASSET` 替换形态。

`From PARALLAX` 展示社区成员发布的真实公开内容。没有公开内容时，整个区块不显示。

## 不上首页

- 不展示开发状态、遥测或调试文本。
- 不展示假增长、假热度、假讨论。
- 不用成员名册填充首页空白。
- 不重复解释同一套分类。
- 不把 Radar 包装成聊天助手。

## 个性化方向

第一版首页使用全站排序。登录后的个性化可以在后续加入：

- 订阅领域优先。
- 读过的来源降权。
- 收藏和评论过的方向升权。
- Radar 保持多样性，不让单一领域长期占满首页。
