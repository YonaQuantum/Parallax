# PARALLAX 界面提示词

下面这段是当前界面方向的主提示词。重点不是“把世界观画满”，而是让用户先感到 PARALLAX 的气质，再进入具体板块。

```text
为 PARALLAX（异视社区）设计一个真实可上线的开源自托管技术社区界面。它不是通用 AI 产品，不是赛博朋克后台管理系统，也不是 GitHub 套皮；它更像一个克制、开放、长期存在的技术研究所与创作社区。

产品范围：
- 社区一级板块为：编程与开源、AI 与模型、游戏与交互、硬件与嵌入式、创作与媒体、科学与宇宙。
- 光谱科学不是一级栏目，而是游戏与交互、创作与媒体、科学与宇宙之间的交叉标签。
- 社区也是游戏工作室雏形，游戏与交互板块要能沉淀玩法、工具链、实时模拟和技术实验。
- 用户可以发布文档、文章、视频、图文和讨论。
- AURA 身份证是社区身份层：初创成员使用月光卡，普通成员使用白卡。
- 页面必须坚持真实数据，不允许用假文章、假评论、假统计制造热闹。
- PARALLAX Radar 是社区的后台信息循环系统，不是聊天助手，不主动占据首页。

核心气质：
- 克制、冷静、开放、实验室感。
- 页面首先依赖 typography、spacing、hierarchy、composition。
- 不依赖 card、border、badge、gradient、icon、status panel 制造完成度。
- 用户先感觉到系统存在，而不是读到系统说明。
- 世界观藏在材质、留白、结构和动效里，不写成调试文案。
- 首页负责建立好奇心，不负责解释完整信息架构。
- 禁止为了填充空白而增加内容，留白本身是设计元素。
- 同一个信息只允许出现一次。
- 一个页面最多一个主强调色。
- 如果一个组件删除后不影响用户理解，就删除。

视觉方向：
- 95% 使用深黑、极深蓝、冷灰和白。
- PARALLAX Yellow #ffd400 是唯一主强调色，只用于关键交互和少量活跃信号。
- 不使用红、蓝、紫给每个分类抢注意力；分类默认低调，hover 或状态变化时才出现黄色。
- 网格背景可以保留，但透明度很低，像环境噪声，不像设计元素。
- 避免大量边框。只保留少数关键结构线，不能让页面像开着辅助线。
- 避免圆角。需要形状时使用矩形、切角、多边形和硬边遮罩。
- 首页保留一个大尺度 PARALLAX 视差环。圆环是底层涂层，不和文字内容混成一个图层；滚动时文字板块缩小并上移，下面内容上浮，背景逐渐模糊，圆环保持固定。

首页结构：
- 顶部导航保持极简：PARALLAX、探索、动态、名册、共建、搜索、登录、发布。
- 首屏只保留：
  - PARALLAX
  - “一个开放的技术与创作社区。”
  - “编程、AI、游戏、硬件、创作与科学在这里交汇。”
  - 进入 PARALLAX
  - 开始创作
- 不要在首屏展示站点遥测、Radar 状态、假热度、重复分类说明或开发阶段文案。
- 分类入口只出现一次，作为 Depth Deck / Signal Deck：
  - CODE
  - AI
  - GAME
  - HARDWARE
  - MEDIA
  - SCIENCE
- Deck 不做普通 Carousel，也不做横排卡片；所有平面基本正面，通过 Z 轴、缩放、位移、透明度和模糊形成 Vista Flip 3D 式的空间堆叠。

页面关系：
- 首页建立气质和入口。
- 探索页承载分类、真实内容和搜索。
- 观测台承载 World Signals、资料摄入和研究队列。
- 成员页承载 AURA 名册。
- 创作台承载发布流程。

禁忌：
- 不要把部署状态、内部标识、调试字段或种子数据状态放进首页 Hero。
- 不要同一套分类讲三遍。
- 不要让每个元素都证明自己有设计感。
- 不要使用无实际功能的系统状态、遥测或调试文本作为装饰。
- 不要主动增加营销式副标题或解释性文字。
- 不要使用大量圆角卡片。
- 不要使用一大片紫蓝渐变当万能背景。
- 不要使用假数据、假热榜、假 AI 研究成果。
- 不要把 AI 做成聊天悬浮窗。
- 不要让界面看起来像 SaaS 控制台、IDE 插件主页或仪表盘。
```
