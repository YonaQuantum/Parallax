# 设计原则

PARALLAX 是克制、开放、理性、带有研究机构气质的技术社区。

页面首先依赖：

- typography
- spacing
- hierarchy
- composition

页面不依赖：

- 无功能的状态面板
- 调试文本
- 多色栏目系统
- 为填空而存在的卡片
- 伪实时数据

## 首页

首页只回答三件事：

1. 这里是什么。
2. 外部世界现在有什么真实变化值得看。
3. 社区内部最近有什么真实创作值得读。

光环是视觉锚点，不承载统计和系统状态。`New` 只展示真实 Signal 和真实社区内容；没有数据时不渲染该区块。

## 颜色

默认使用深黑、冷灰、白和一个主强调色。`NEXT_PUBLIC_SITE_ACCENT` 控制主强调色，默认是 PARALLAX Yellow。

同一页面最多一个主强调色，不使用六种颜色区分六个栏目。

## Radar 呈现

Radar 不作为聊天助手出现。前端展示的是 Radar 发现的外部 Signal，而不是 Radar 自身的运行状态。

每条 Signal 必须有来源、链接、领域、标签和短摘要，不伪装成社区成员原创。
