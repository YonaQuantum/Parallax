# 产品记忆

这份文档记录 PARALLAX 的产品判断，供开发者和 AI 协作者在修改界面、文案和 Radar 逻辑前阅读。它不是临时需求池，而是避免反复改坏同一块体验的记忆层。

## 首页新信号

- `新信号` 展示社区正在发生的内容和 Radar 摄入的外部信号。
- 外部信号不是帖子，不能伪装成成员原创。
- 首页优先展示有中文 `displayTitle`、中文摘要、来源和缩略图的外部信号。
- 原始标题要保留用于溯源，但中文界面不要直接把英文新闻标题当主标题。
- 摘要要像编辑转述：明确、克制、可信。不要使用“可能影响”“可能扩展”“可能提供线索”这类无自信模板。
- 证据不足时降低置信度或归档，不用空洞句子占首页。
- 外部信号会自动软回收到 `deepArchivedAt`，社区成员发布的 `Content` 不参与回收。

## 新信号卡片动效

- 首页新信号最多展示六个卡片槽位。
- 新信号默认保持静态矩阵，不做自动轮播、自动翻转或进度条。
- 不用 3D 翻页、百叶窗、跑马灯等廉价动效来伪装内容流动。
- 内容流动来自 Radar 和社区发布的真实更新；没有高质量交互方案时，保持安静。
- 悬停反馈只做轻微明度、图片和文字变化，不改变内容本身。

## 领域索引

- 六个领域入口是社区长期结构，不是营销卡片。
- 领域索引要保持清楚、安静、可扫读。
- 不使用六种主题色区分领域。
- 不为了显得高级加入无意义状态、编号解释或装饰面板。
