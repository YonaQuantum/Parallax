# 资料源地图

这是 PARALLAX Radar 第一阶段的资料源分层。它解决的问题不是“自动写内容”，而是让社区首页持续感知外部世界正在发生什么。

## 编程与开源

关注语言、框架、操作系统、数据库、Web、Linux、开源项目、开发工具和工程实践。

优先来源：

- GitHub Search：近期仍活跃、star 高或增长快的项目
- 语言和框架官方博客
- 数据库、浏览器、Linux、开发工具 release feed

判断重点：

- 最近是否仍在维护
- license 是否清楚
- 是否有 demo、release、文档或可运行样例
- 是否能转化为教程、工具链或社区共建任务

## AI 与模型

关注大模型、多模态、智能体、推理、模型发布、开源模型、训练、RAG、推理框架和论文。

优先来源：

- arXiv AI / 智能体 / Multimodal 查询
- Hugging Face blog / model release feed
- OpenAI-compatible、本地推理、embedding / rerank 工具链

判断重点：

- 是否能本地运行，尤其是否适合 GPU 工作站
- license 是否允许社区或工作室使用
- 是否能成为 PARALLAX Radar、检索或创作管线的一部分
- 是否只是营销噪声

## 游戏与交互

关注游戏开发、Godot、Unreal、Unity、独立游戏、游戏设计、XR、交互设计和实时模拟。

优先来源：

- Godot / Unreal / Unity 官方 feed
- 独立游戏技术博客
- 引擎、编辑器、关卡生成、交互原型相关开源项目

判断重点：

- 是否能做原型
- 是否能启发玩法、交互或工具链
- 是否有可复用机制
- 是否适合转化为工作室实验

## 硬件与嵌入式

关注 MCU、ESP32、STM32、Linux 板卡、机器人、电子、传感器、芯片、DIY Hardware、Raspberry Pi 和 FPGA。

优先来源：

- Hackaday / embedded blog RSS
- 开源硬件项目
- 板卡、机器人、传感器和 FPGA 工具链

判断重点：

- 是否真实可复现
- 物料、成本和安全性是否现实
- 是否能连接软件、游戏交互或科学观测

## 创作与媒体

关注音乐、声音设计、数字艺术、3D、动画、图形、摄影、影视和创作工具。

优先来源：

- Blender、音频工具、视觉工具和生成艺术项目
- Shader、WebGPU、Vulkan、实时渲染资料
- 数字艺术和创作工作流文章

判断重点：

- 是否能产出作品或工具
- 是否能形成社区独特视觉/声音语言
- 是否能和游戏、AI、硬件或宇宙主题发生交叉

## 科学与宇宙

关注天文学、航天、物理、数学、生命科学、新材料、科学发现、科研工具、宇宙生命和科学哲学。

优先来源：

- NASA / ESA 等公开 RSS
- 科研机构和论文源
- 宇宙生命、费米悖论、意识、科学哲学相关长文

判断重点：

- 科学可信度
- 想象力价值
- 是否能转化为文章、设定、游戏原型、视觉实验或讨论入口

## 光谱科学的位置

光谱科学不再作为一级板块，而是“游戏与交互”和“科学与宇宙”之间的重要交叉标签。它可以连接光谱渲染、天文光谱、声谱可视化、波长、色散、散射和科学仪器视觉语言。

## LLM 参与边界

第一阶段的摄入必须在没有大模型时也能运行：抓取、去重、来源归类、热度衰减和基础噪声判断都由确定性规则完成。

大模型只作为增强层参与：

- 生成摘要
- 解释为什么值得看
- 标记跨领域标签
- 给出人工接管建议
- 识别明显营销、标题党或低质量来源

如果 LLM 不可用，Radar 仍然写入带来源的基础 Signal；如果 LLM 可用，再补充解释层。
